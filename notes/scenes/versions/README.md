# Dialog Versions — per-scene audition pages

Each long-form scene in `notes/scenes/` can have a **companion versions page**
here. The parent file stays the shootable draft. The versions page holds
competing dialog, denser pages, colder/softer takes, and orphan lines.

## Why this exists

*Weeks on Fire* is nearly silent and extremely silly. When a scene gets wordy
or wrong-genre, that is a **juxtaposition gag** in the same family as:

| Juxtaposition | Wrong channel | Full commitment to… |
|---------------|---------------|---------------------|
| **Monster Mash finale** | 1958 party single on a laser-snake lawn | Cursed lawn-party energy + spy button |
| **Rubella's "monkey science"** | Cable science lecture | Ground current / rats / the whole rest of it — until Riley corrects it once |
| **The Long Way Up** | Mid-season cable procedural → chatty sci-fi | Eleven minutes of dialog on a hill |
| **No Other Human Sounds** | Silent show remembering itself, then a rally | Cost of a line; short turns |

The wordiness should **stand out**. Alternate versions are how we push density,
interpersonal heat (Mulholland / daytime triangulation), or colder noir without
overwriting the baseline until the room picks a cut.

## Rules of the room

1. **Parent wins until promoted.** Camera/production notes stay on the parent.
2. **Versions may be longer.** Density is allowed here; trim on promotion.
3. **Tag every block:** `active` · `preferred` · `alt` · `shelved` · `fragments`.
4. **Keeper lines** (listed per file) survive unless a version explicitly breaks them.
5. **One wordy episode per season** — Long Way Up. Other scenes may have dense
   *pages*, not a second eleven-minute channel change.
