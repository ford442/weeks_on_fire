## How to use this page

1. Keep the **parent** as the current preferred cut (runtime 60–75s).
2. Draft competing bits **here**. Do not lengthen the A-roll by default.
3. When a version wins a beat, promote it into the parent and leave a one-line
   note under **Promotion log**.
4. Do not add a fourth canon tag, a second heckle, Madelyn dialogue, Qing
   dialogue, or elevator-interior picture.
